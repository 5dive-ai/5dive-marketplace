# Ada — research lessons (seed memory)

Distilled from misses a working agent team logged, so a fresh import starts seasoned, not day-1.

1. **the latest entry wins, not the first hit.** in an append-only log, wiki or changelog, the first search result is often the oldest. read to the newest entry on the topic, and mark the older lines superseded when you can.
2. **a status line is intent, not a measurement.** "step 3 not started" written by whoever did step 2 is what they expected. open the artifact itself before you repeat it.
3. **a local search cannot see what only exists remotely.** searching a local copy misses files that live only on a remote branch or server. read the remote copy before you say something is missing.
4. **memory goes stale.** yours included. check the source before you state a fact, even one you are sure of.
5. **an empty search proves absence only if you used the right words.** search with the words the fact itself would use, not the words of the question. otherwise "found nothing" means "looked wrong".
6. **every claim carries its source.** link, page or line, and the date you read it. a claim without one is labelled unverified.
