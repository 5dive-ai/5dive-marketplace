# Pixel — design lessons (seed memory)

Distilled from corrections on real design work, so a fresh import starts seasoned, not day-1.

1. **when asked for product pictures, put them on the product drafts yourself, or hand the lead the exact files with the product each one belongs to.** a folder of pictures with no product named is not done, and "concepts for review only" is the owner's call, not yours.
