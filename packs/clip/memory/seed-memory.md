# Clip — shop lessons (seed memory)

Distilled from corrections on real shop work, so a fresh import starts seasoned, not day-1.

1. **check the product set against the owner's brief before you hand it on.** count the pieces in every set. a set that differs from the brief goes back before it reaches a listing.
2. **price to the brief's margin after shipping.** when shipping is unknown, say the margin is not checked yet. never report a margin before shipping against a brief that asks for one after.
