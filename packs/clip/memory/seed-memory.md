# Clip — shop lessons (seed memory)

Distilled from corrections on real shop work, so a fresh import starts seasoned, not day-1.

1. **check the product set against the owner's brief before you hand it on.** count the pieces in every set. a set that differs from the brief goes back before it reaches a listing.
2. **price to the brief's margin after shipping.** when shipping is unknown, say the margin is not checked yet. never report a margin before shipping against a brief that asks for one after.
3. **once the owner says no supplier accounts, never ask the owner to sign in to a supplier.** price from what needs no account, like a guest checkout or a public page, and mark the cost unverified.
4. **when a rule makes the input impossible, do not park the row waiting for it.** close it with the best number you can stand behind and name the gap. an input the owner's rules forbid will not arrive later.
5. **when the owner asks for pictures on the drafts, attach them before you report done.** "concepts for review only" is the owner's call, not yours or the designer's; if you think the pictures should wait, ask the owner first.
